# instagram/

Artes finais das peças do perfil @henriqueenofc, hospedadas aqui apenas para que o agendador (Metricool) consiga baixá-las por link público e permanente.

Estrutura: `instagram/AAAA-MM-DD/<peça>.jpg|mp4` — uma pasta por data de publicação.

URL pública de cada arquivo: `https://raw.githubusercontent.com/ATOSCOMPANY/teste_eqr/main/instagram/AAAA-MM-DD/<arquivo>`

## tools/
`tools/make_story.py` — gera a arte 1080x1920 (foto + gancho + frase-síntese + corpo + bordão + etiqueta de série) com Python/PIL. Ver docstring para o spec JSON.
